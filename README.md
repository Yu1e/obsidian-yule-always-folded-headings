<details>
<summary><b>🇬🇧 English</b></summary>

Headings prefixed with an empty comment ` %% %% ` (note the spaces) are always collapsed when opening a note. If you expand them and then navigate away, they will automatically collapse again. The empty comment is hidden in Live Preview.

Example:

`#### %% %% Heading`

Headings whose text starts with a hyphen are always collapsed too. The hyphen stays visible.

Example:

`### -Heading`

### Installation
Available exclusively via **BRAT** or **direct file copying**.

### Что делает этот плагин

Если в начало заголовка добавлен пустой комментарий ` %% %% ` (пробел между двойными процентами, до и после них), такие заголовки всегда будут свёрнуты при открытии заметки. Если их раскрыть и потом выйти из заметки, будут снова показаны свёрнутыми при следующем входе в заметку. Пустой комментарий скрывается в режиме Live Preview.

**Пример заголовка:**

`#### %% %% Заголовок`

Заголовки, текст которых начинается с дефиса, тоже всегда свёрнуты. Дефис остаётся видимым.

**Пример заголовка:**

`### -Заголовок`
